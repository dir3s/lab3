# Правила розробки проекту
1. Перед початком роботи оновлюйте проект через git fetch та перевіряйте стан репозиторію через git status.
2. Для кожного нового завдання створюйте окрему гілку feature/*.
3. Робіть коміти зі змістовними повідомленнями.
4. Завжди перевіряйте стан файлів через git status та git diff.
5. Не додавайте тимчасові файли та секрети до репозиторію
